AI Mock Interview Application

An AI-powered web application designed to help students prepare for technical interviews through AI-generated interview questions.

Overview

This project aims to make interview preparation easier by providing a simple platform for practicing technical interview questions using Google's Gemini API.

Key Features

- AI-generated technical interview questions
- Interactive interview practice
- Simple and user-friendly interface
- AI integration using the Gemini API

Technology Stack

- Language: Python
- Framework: Flask
- AI API: Google Gemini API

Learning Outcomes

- Python application development
- Web application development using Flask
- Integration of generative AI APIs
